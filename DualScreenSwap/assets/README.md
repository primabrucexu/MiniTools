# 程序图标

`DualScreenSwap.png` 是透明背景原稿，使用内置 `image_gen` 工具生成并简化；`DualScreenSwap.ico` 由同一原稿按 Windows 图标格式打包，包含 16、20、24、32、40、48、64、128、256 像素九个尺寸，保留透明通道。

构建通过 `/win32icon`（或项目的 `ApplicationIcon`）把 ICO 嵌入 EXE。托盘和设置窗口从当前 EXE 取得相同图标，运行时不依赖此目录。

## 初始生成提示词

Use case: logo-brand. Asset type: a finished Windows desktop utility app icon, square composition, transparent background. Primary request: create a crisp, memorable icon for DualScreenSwap, a tiny app that swaps windows between two monitors. Subject: exactly two clear compact computer monitor/window silhouettes connected by two short bold opposing arrows, visually communicating swap. Modern native Windows utility aesthetic; clean rounded geometry and confident thick strokes, restrained dimensional polish, legible at 16, 24, 32 and 48 pixels. Keep the icon balanced and centered with a small safe margin. Strong foreground contrast that works against both light and dark taskbars. No words, letters, numbers, watermark, decorative particles, tiny controls, or surrounding scene. The background must be truly transparent, not a checkerboard image. Output one icon only, not a grid of alternatives.

## 最终简化提示词

Refine this app icon for legibility at 16–32 px. Keep exactly the same concept: two blue computer monitors and two opposing green swap arrows, no text, transparent background. Change the composition to a compact nearly square emblem: two simple monitor silhouettes staggered diagonally with modest overlap, connected by two thick opposing arrows. Remove the heavy white double outlines, shine, glass streaks, and small details. Use cleaner flat shapes with modest depth and fewer outlines; preserve strong contrast on both light and dark Windows taskbars. Center the graphic and make it occupy roughly 85 percent of both the square width and height, with equal small transparent margins. A professional understated Windows productivity utility icon, not a web banner. One finished icon only.
