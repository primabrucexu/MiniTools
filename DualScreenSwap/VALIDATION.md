## 复现测试

先退出双屏窗口互换工具，再在普通 Windows 桌面会话的项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run-tests.ps1
```

配置测试会短暂写入应用配置文件，并在 `finally` 中恢复测试前内容；运行测试时不要同时保存设置。

需要验证真实双屏窗口移动时：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run-tests.ps1 -IncludeWindowIntegration
```

窗口测试会暂时显示自有测试窗口。保持桌面空闲约十秒；如果目标窗口不是测试夹具，预检会停止交换。

受限沙箱可能禁止注册全局快捷键并返回 Windows 错误 5；本次真实注册和窗口测试在获得运行许可的桌面上下文中完成。错误 5 与占用错误 1409 不同。

本机没有 .NET Framework 4.8 Targeting Pack。直接使用旧版 MSBuild 时会有引用程序集/架构警告，因此使用 `build.ps1` 作为本机验证通过的构建入口；Visual Studio 工程供安装了对应开发工具的环境使用。
