# 抖音直播清理（DouyinLiveClean）

一个用于 Tampermonkey（油猴）的脚本。当前版本为 **1.3.0**，进入直播间后自动完成三项设置：

- 关闭画面上的弹幕，保留右侧聊天区。
- 开启网页的“屏蔽礼物特效”选项。
- 选择当前可用的最高画质，遵守网页已有的档位限制。

## 安装与更新

1. 在浏览器中安装并启用 Tampermonkey。
2. 点击“添加新脚本”，将 [douyin-live-clean.user.js](douyin-live-clean.user.js) 的全部内容替换到编辑器中。
3. 按 `Ctrl + S` 保存，再刷新抖音页面。

更新时直接替换已有脚本的全部内容。仅保留一个版本启用，避免不同版本相互干扰。脚本没有外部运行依赖，使用时不需要 Node.js。

## 生效范围与行为

- 独立直播间：`https://live.douyin.com/直播间编号`。
- 主站关注页直播：`https://www.douyin.com/follow/live/直播间编号`。
- 支持站内导航进入直播间和切换房间。脚本在主站预先加载，以接住不刷新页面的导航；普通短视频页不会执行设置。

脚本直接调用网页原生状态和播放器方法，三项分别等待自己的接口就绪，可以在同一轮发起。实际画质切换仍需等待播放器和网络。

初始化完成后不持续强制设置，可以手动重新开启弹幕或特效、调整画质。初始化期间手动操作相应控件，也会让出该项控制。刷新、换房或播放器实例更换时重新初始化。

页面可见且接口未就绪时，会尝试等待约 30 秒；某项失败不阻塞其他项。缺少原生接口时会报告未完成项目，不会退回模拟鼠标点击。

在 **DouyinLiveClean 目录**执行：

```powershell
npm ci --prefix .\tests
```

## 限制与排查

脚本依赖抖音内部状态和播放器接口，这些不是稳定的公开 API，网页改版后可能需要适配。脚本不会自动登录或绕过受限画质档位。

如果某项没有生效：

1. 确认油猴中仅启用了一个版本，刷新并进入上述支持的直播页面。
2. 查看原生设置面板：“弹幕开关”应关闭，“屏蔽礼物特效”应开启，清晰度应为当前可选最高档且不是自动模式。
3. 打开浏览器开发者工具的控制台，查找包含“抖音直播清爽”的提示。反馈时提供直播间网址及相关提示，便于定位接口变化。
